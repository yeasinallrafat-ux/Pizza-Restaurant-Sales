
# 🍕 Pizza Restaurant Sales Analysis Using SQL

## 📌 Project Overview

This project analyzes pizza restaurant sales data using SQL to understand order trends, customer purchasing behavior, and overall revenue. The analysis focuses on monthly orders, peak ordering hours, average pizzas per order, and total revenue generated.

## 🎯 Project Objectives

- Analyze monthly order trends.
- Identify peak hours for pizza orders.
- Calculate the average number of pizzas per order.
- Determine total revenue generated.
